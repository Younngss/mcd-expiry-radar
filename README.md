# 麦麦到期雷达

**用好已有的每一份权益。** 基于麦当劳中国 MCP，把本人优惠券、到期积分和近期活动整理为行动清单，支持交互筛选、使用条件核对和日历提醒导出。

2026 麦当劳程序员创意开发大赛参赛项目。独立开发，非麦当劳官方产品。

![麦麦到期雷达模拟演示截图](https://github.com/user-attachments/assets/59b63a53-9f78-4276-96d5-5f371ca2206d)

## 解决什么问题

卡包里有券，却记不清什么时候到期；积分只有月度到期汇总；商城里标记“上架”的活动也可能早已过了兑换截止时间。麦麦到期雷达把这些信息放到同一张清单中，优先提醒用户核对已有权益，再按需求考虑活动和可领券。

目标用户：已有麦当劳会员权益、希望减少遗忘和无效操作的上班族、学生与家庭用户。

## 立即体验

需要 Python 3.11+，不需要安装第三方依赖。下载项目后，在项目目录运行：

```sh
python3 radar.py demo
python3 radar.py serve --port 8765
```

打开 <http://127.0.0.1:8765>。也可以直接用浏览器打开 [docs/demo.html](docs/demo.html)。公开演示使用固定在 **2026-10-10** 的模拟数据，每条示例均标记“演示”；不会连接账号，不代表官方实时活动。

体验流程：点击“7 天内到期” → “查看条件” → “选中当前可提醒项” → “导出选中提醒” → 手动导入自己的日历。提醒需要完成导入才会生效；相同事项使用稳定 UID，日历软件的重复导入行为以其自身规则为准。

## 查询自己的真实权益

在 [麦当劳 MCP 官方平台](https://open.mcd.cn/mcp) 登录并申请自己的 Token。在本机创建 `.env`，内容参考 [.env.example](.env.example)，填写 `MCD_MCP_TOKEN`。也可通过系统环境变量提供凭据。不要把真实 Token 放到源码、公开聊天、截图或配置示例中。

```sh
python3 radar.py live --evidence
python3 radar.py serve --file .private/dashboard.html --port 8766
```

打开 <http://127.0.0.1:8766>。如果端口被占用，换一个端口；停止预览按 Ctrl+C。

真实报告写入当前目录的 `.private/`，包含个人 HTML、JSON 与文字清单；文件仅允许本人读写。真实日历需要在页面选择条目后手动导出。`.env` 和 `.private/` 已被 Git 忽略，发布前仍须执行下面的发布检查。页面是查询快照，不会自动刷新；更新权益需重新运行 `live`。页面不加载远程图片、字体、分析脚本，也不携带凭据。

部分工具失败时仍会生成清单，缺失数据明确标注为不可用，程序退出码为2；认证或整体连接失败为1，完整成功为0。

## 作为 Skill 使用

完整技能位于 [skills/mcd-expiry-radar](skills/mcd-expiry-radar/SKILL.md)，包含规则、查询程序和界面模板，可整体导入支持 `SKILL.md` 的智能体客户端。导入入口以客户端说明为准。技能无需依赖本项目根目录的程序。

可用提示语：

> 使用麦麦到期雷达，看看我的券这周有哪些快过期了。先核对已有权益，不用为用券额外消费。

> 我的积分本月有多少要过期？区分官方提供的信息和需要进一步核验的条件。

> 帮我整理近期活动和已有优惠券，我自己选需要导入日历的提醒。

如客户端支持 MCP 配置，参考 [mcp-config.example.json](mcp-config.example.json)。`${MCD_MCP_TOKEN}` 是环境变量占位符，各客户端的变量替换支持不同，请按其说明设置；不要把未展开的占位符当作真实 Token。本项目命令行直接读取环境变量或 `.env`。

## 设计亮点

- **已有权益优先**：优惠券按到期紧急程度排序，未生效、已过期和待核验状态分开显示。
- **处理真实数据问题**：上架状态与有效期交叉核验，过滤已过期商城条目；分页未完整读取时明确说明范围。
- **不制造“省钱数字”**：官方“用券价格”原样标明，不累加为节省金额；积分不折算为现金。
- **提醒可携带**：选择所需事项导出标准 ICS，优惠券到期日、活动展示日和积分核对日有不同说明。
- **只读查询**：客户端只允许六个查询工具，不包含领券、兑换、点餐、支付或抽奖调用。

卡包持有不保证当前门店或订单可用；日期有效也不保证当前用餐时段适用。兑换积分、兑换现金和券核销额外成本需要分别核验。本项目不提供医疗或营养建议。
